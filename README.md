# SiteCreator

SiteCreator helps you find local businesses and quickly make a modern website for them.

It is made for people like freelancers, agencies, and marketers who want to spend less time setting up websites and more time improving them.

## What it can do

- Search for local business leads
- Create a website based on the business type
- Edit the website with AI prompts
- Preview changes while you work
- Publish the website to GitHub
- Deploy it to Vercel

## How it works

1. Search for a business or category, such as `Dentists in Manhattan`.
2. Pick a business you want to make a site for.
3. Create a new website project.
4. Use the AI editor to change the text, colors, layout, or sections.
5. Publish the finished site to GitHub and Vercel.

## Built with

- Next.js, React, TypeScript, and CSS
- Express and Node.js
- MongoDB and Mongoose
- GitHub CLI and Vercel CLI
- `node-pty` for running separate site projects

## Running it locally

You will need Node.js, MongoDB, GitHub CLI, Vercel CLI, and AntiGravity CLI installed and signed in.

Start the backend:

```bash
cd server
npm install
npm run build
npm start
Then start the frontend in another terminal:
cd client
npm install
npm run dev
The frontend should open at http://localhost:3000.
